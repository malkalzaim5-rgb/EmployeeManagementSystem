\# Employee Management System (EMS)



A full-featured web portal built with \*\*ASP.NET Core MVC\*\* to streamline employee administration, departmental structuring, and payroll management with secure enterprise-grade authentication.



\## 🚀 Key Features



\- \*\*Role-Based Access Control (RBAC):\*\* Configured with ASP.NET Core Identity to manage permissions across Administrators and Staff.

\- \*\*Employee \& Department Management:\*\* Full CRUD operations for managing employee profiles, assignments, and organizational units.

\- \*\*Salary \& Payroll Tracking:\*\* Dedicated module for computing, recording, and auditing employee compensation.

\- \*\*Security \& Integrity:\*\* Robust password policies, brute-force lockout mechanisms, and anti-forgery token verification.

\- \*\*Responsive UI:\*\* Built using Bootstrap to deliver an optimal user experience across desktop and mobile screens.



\## 🛠️ Built With



\- \*\*Framework:\*\* ASP.NET Core MVC

\- \*\*Language:\*\* C#

\- \*\*ORM:\*\* Entity Framework Core

\- \*\*Database:\*\* Microsoft SQL Server

\- \*\*Security:\*\* ASP.NET Core Identity

\- \*\*Frontend:\*\* Razor Views, Bootstrap, HTML5, CSS3, JavaScript



\## ⚙️ How to Run



1\. Clone the repository:

git clone https://github.com/malkalzaim5-rgb/EmployeeManagementSystem.git



2\. Go to project directory:

cd EmployeeManagementSystem



3\. Update Connection String in appsettings.json



4\. Apply Database Migrations:

dotnet ef database update



5\. Run the application:

dotnet run
